# 🛠️ Meshropractor

[[English version](README.md)]

**Meshropractor** — открытый промышленный программный комплекс для инженеров-конструкторов, расчетчиков и технологов аддитивного производства (SLM/DMLS 3D-печать металлом), литья и обратного инжиниринга. Программа сопоставляет номинальную CAD-геометрию с оптическим или томографическим 3D-сканом реальной детали, рассчитывает непрерывное поле деформаций и выполняет инвертированную компенсацию усадок, термических поводок и остаточных напряжений.

Вместо устаревших и требовательных к оперативной памяти RBF-матриц ядро программы переведено на нейросетевое представление деформаций (Neural Deformation Fields на базе PyTorch с Fourier-кодированием NeRF) с аппаратным ускорением NVIDIA CUDA, сокращая расчет деталей на 3+ млн полигонов с 12 часов до 5 минут.

## 💡 Основные сценарии применения

* **Селективное лазерное сплавление (SLM / DMLS):** Компенсация термических деформаций, закручивания пера турбинных лопаток и отрыва поддержек при печати жаропрочными сплавами (Inconel, титан, нержавеющие стали).
* **Литейное производство и пресс-формы:** Коррекция формообразующих поверхностей с учетом анизотропной усадки металла.
* **Контроль геометрии (ОТК):** Построение цветовых карт отклонений (Signed Distance Heatmap) и точечные замеры припуска/недолива.

## 🚀 Архитектура и функциональные модули

### 1. Промышленное совмещение (GOM-Style Alignment)
* **Честные нормали CAD:** Извлечение точных геометрических нормалей граней через Trimesh без интерполяционных искажений.
* **Ручное позиционирование по маркерам:** Расстановка сопряженных точек-маячков на 3D-сцене с помощью аппаратного лучемета.
* **Глобальный автопилот (Best-Fit):** Совмещение центроидов и глобальный поиск соответствий через FPFH-дескрипторы (алгоритмы Fast Global Registration и глубокий RANSAC).
* **Анализ симметрии (Anti-Flip):** Автоматическое распознавание и устранение переворота сканов симметричных деталей.
* **4-стадийный Robust Multi-Scale ICP:** Многомасштабная подгонка поверхностей с функцией потерь Тьюки (Tukey Loss, коридор захвата от 8% до 0.2% от габарита модели) для полного отсечения налипшего порошка и брызг.
* **Контроль перекрытия (Fitness):** Защита от ложноположительного занижения RMSE при неполном или угловом контакте деталей.

### 2. Нейросетевое ядро предеформации (Neural Deformation Engine)
* **Fourier Feature Encoding (Positional Encoding):** Проекция координат в высокочастотный базис синусов и косинусов (как в NeRF), снимающая spectral bias и позволяющая MLP улавливать резкие перегибы кромок и сложную кривизну пера.
* **Zero-Copy GPU Training:** Обучение на тензорах, перманентно загруженных в VRAM, с прямой нарезкой батчей через `torch.randperm` в обход оверхеда Python `DataLoader`.
* **Смешанная точность (AMP / FP16):** Активация тензорных ядер (Tensor Cores) видеокарт NVIDIA RTX с сохранением `float32` точности на выходе.
* **Векторизованный Raycasting с истинной фильтрацией:** Аппаратный поиск отклонений по нормалям с отсечением слепых зон сканера (в датасет попадают только подтвержденные измерения, а теневые участки сеть интерполирует гладко).
* **Архитектурные режимы:**
  * `Мягко (Soft)`: Жесткая фильтрация шума сканирования.
  * `Нормально (Medium)`: Сбалансированная модель для типовых машиностроительных деталей.
  * `Жестко (Hard)`: Детализированный MLP с контролем локальной гладкости поля (Smoothness Penalty).
* **Анизотропная компенсация:** Раздельное масштабирование деформации в плоскости построения слоев ($F_{xy}$) и по оси роста детали ($F_z$).
* **Безопасная топология:** Валидация сетки без объединения близких вершин, исключающая повреждение топологии острых кромок.

### 3. Анализ отклонений и визуализация
* **Цветовая карта отклонений (Heatmap):** Градиентная шкала знаковых расстояний (Signed Distance) с настройкой пределов.
* **Интерактивные выноски (GOM Callouts):** Клик левой кнопкой мыши по любой точке скана выставляет ярлык с точным числовым отклонением в миллиметрах (красный — наплыв/припуск, синий — усадка).
* **Векторное поле смещений (Quiver 3D):** Отображение 3D-стрелок деформации поверх модели для оценки пространственного кручения и прогибов.
* **Гибкое управление отображением:** Контекстные меню для каждой детали с 8 режимами отрисовки (*Затенение, Треугольники, Затенение+Каркас, Каркас, Ограничивающий параллелепипед, Прозрачность, Без затенения, Скрыть*) и быстрой регулировкой прозрачности (0–80%).

### 4. Подготовка производства и слайсер
* **Менеджер платформ:** База данных принтеров с возможностью задания нестандартных габаритов рабочих плит.
* **Запретные зоны (Keep-Out Zones):** Настройка цилиндрических и прямоугольных мертвых зон крепления плит с ограничением по высоте.
* **Метрология сетки:** Мгновенный расчет объема тела ($\text{мм}^3$), площади ($\text{мм}^2$), габаритного параллелепипеда (Bounding Box) и триангуляции.
* **Формат проектов (`.mrp` v1.4):** Сжатый архив, сохраняющий модели CAD, сканов, результатов компенсации, маркеры, платформы и визуальные настройки сцены.

## ⚙️ Установка и запуск

### Системные требования
* Python 3.10 или выше
* Видеокарта NVIDIA с поддержкой CUDA (рекомендуется серия RTX 2060 / 3060 и новее)
* *(При отсутствии видеокарты NVIDIA программа автоматически переходит на многопоточный режим CPU)*

1. **Клонирование репозитория:**

   ```bash
    git clone [https://github.com/B0ogie888/Meshropractor.git](https://github.com/B0ogie888/Meshropractor.git)
    cd Meshropractor

2. **Настройка виртуального окружения:**

   ```bash
    # Для Windows
    python -m venv .venv
    .\.venv\Scripts\activate

    # Для Linux / macOS
    python3 -m venv .venv
    source .venv/bin/activate
   
3. **Установка PyTorch с поддержкой CUDA:**
Перед установкой общих зависимостей установите сборку PyTorch с поддержкой CUDA:

   ```bash
   pip install torch torchvision torchaudio --index-url [https://download.pytorch.org/whl/cu121](https://download.pytorch.org/whl/cu121)
   
4. **Установка PyTorch с поддержкой CUDA:**
    ```bash
   pip install -r requirements.txt
   
5. **Запуск:**
    ```bash
   python src/Meshropractor.py
   
## 🖥️ Оформление и системная совместимость
* Интерфейс принудительно зафиксирован в темно-серой палитре (#2b2b2b) с использованием движка Fusion и прямого обращения к WinAPI (DwmSetWindowAttribute).
