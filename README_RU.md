# Meshropractor

[English](README.md) · [История изменений](CHANGELOG.md) · [Проверки и ограничения](docs/VALIDATION.md)

Meshropractor — настольное приложение для подготовки 3D-деталей и компенсации
геометрических отклонений по данным сканирования. Версия 0.2.5 объединяет два рабочих
пространства:

- **Слайсер:** импорт STL/STEP, исправление и редактирование сеток, размещение деталей, просмотр сечений,
  выделение поверхностей, автоматические и ручные поддержки, геометрические измерения.
- **Предеформация:** совмещение CAD со сканом, карты отклонений, обучение поля смещений
  и расчёт компенсированной модели с экспортом в STL.

Проекты `.mrp` сохраняют геометрию, результаты и настройки; изменения можно отменять
и повторять. Вывод машинных заданий CLS пока экспериментальный и недоступен из интерфейса.
Подробности возможностей и ограничений приведены ниже.

Интерфейс построен на PySide6 и PyVista/VTK, геометрические расчёты используют Open3D
и Trimesh, импорт STEP — OpenCascade, поле деформации — PyTorch с Fourier-кодированием.

## Установка

Для готовой Windows-сборки используйте установщик `Meshropractor-Setup-0.2.5-x64.exe`
или всю папку `dist\Meshropractor` вместе с `_internal`; Python отдельно не нужен.
Команды создания приложения и установщика: [сборка Windows](docs/BUILD_WINDOWS.md).
Ниже описан запуск из исходного кода.

При запуске приложение проверяет стабильные GitHub Releases этого репозитория на
наличие новой версии с установщиком Windows x64. Скачивание начинается по согласию,
показывает прогресс и допускает отмену. После загрузки задаётся отдельный вопрос об
установке. Перед закрытием можно сохранить проект; затем обновление устанавливается
автоматически с отображением прогресса и запросом прав Windows. После успешной
установки приложение запускается снова; Windows не перезагружается. Версия задаётся в корневом
файле `VERSION`; порядок публикации обновлений описан в инструкции по сборке.

Проверенное окружение: Windows, Python 3.12. Версии прямых зависимостей закреплены
в `requirements.txt`. NVIDIA GPU необязателен: без CUDA обучение выполняется на CPU.
Трассировка лучей Open3D выполняется на CPU пакетами независимо от устройства обучения.

```powershell
git clone https://github.com/B0ogie888/Meshropractor.git
cd Meshropractor
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Выберите одну сборку PyTorch. Для NVIDIA CUDA 12.1:

```powershell
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

Для CPU:

```powershell
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
```

Затем установите зависимости и запустите приложение:

```powershell
python -m pip install -r requirements.txt
python src/Meshropractor.py
```

## Работа с моделями

Вкладка **«Расположение»** объединяет 13 инструментов: точные преобразования,
перетаскивание мышью, ориентацию выбранной поверхности, автоматическую раскладку
на платформе и в её объёме, поиск и сравнение ориентаций, минимизацию габаритов,
подгонку под платформу без изменения масштаба и перенос ориентации на похожие детали.
Предпросмотр, отмена фонового расчёта и Undo/Redo доступны; учитываются поддержки,
невыбранные детали и запретные зоны. [Как работают команды](docs/PLACEMENT.md).

Вкладка **«Исправление»** содержит 25 команд с иконками: автоматическое лечение,
нормали, сшивание, отверстия, дубли и нахлёсты, разделение и булево объединение деталей,
ручные треугольники/перемычки, обрезка плоскостью, перемещение вершин, сокращение,
сглаживание и переразбивка. Команды работают с отмеченными деталями через фоновую
подготовку, предпросмотр и отдельное применение; результат отменяется Ctrl+Z.
Вершины и грани можно выбирать в сцене, вершину — перетаскивать мышью.
Оболочка и переразбивка приближённые, поэтому перед применением нужно проверить форму.
[Команды, порядок работы и ограничения](docs/MESH_REPAIR.md).

**Мастер исправлений** открывается в слайсере через «Исправление → Мастер исправлений»
и кнопкой рядом с загрузкой CAD/скана в предеформации. Выпадающий список содержит
детали всех платформ, дочерние поддержки, CAD, скан и результаты. Карты отклонений
доступны для диагностики; исправляйте их исходную геометрию и пересчитывайте карту.
Полный анализ отдельно считает нахлёсты площадей и пересечения, показывает контуры,
неманифолдные рёбра/вершины, дубли, вырожденные грани, фрагменты и ориентацию.
Счётчики могут отличаться от Magics: используются собственные критерии и точность.

Полное лечение устраняет дефекты связности и пересечения, закрывает границы отверстий
и согласует нормали. Плотную сетку можно предварительно оптимизировать до выбранного
числа треугольников (по умолчанию около 400 тысяч). После лечения выполняются повторный
анализ и двустороннее сравнение формы по всем вершинам и выборке поверхности.
При превышении допуска (по умолчанию 0,05 мм) применение блокируется. Это измеренная
оценка, не строгая граница максимальной ошибки. Процесс запускается по подтверждению,
показывает этапы и допускает отмену. Копию и JSON-отчёт можно сохранить до применения.
Полный анализ многомиллионного STL может занять более десяти минут.
Фрагменты не удаляются автоматически; возможный шум только отмечается в отчёте.
При смене триангуляции геометрия поддержек сохраняется, привязки к старым номерам
граней сбрасываются. [Подробнее о проверках](docs/MESH_REPAIR.md).

Перед загрузкой программа спрашивает, запускать ли диагностику и подготовку лечения.
«Загрузить без лечения» пропускает оба этапа; вопрос появляется до тяжёлых расчётов.
Если проверка нужна, выберите от одного до трёх проходов и максимальный размер отверстия
(по умолчанию 0,1 мм). Текущий этап показывается в строке состояния и журнале;
отмена проверяется между этапами и при обходе отверстий. После подготовки результата
появляется отчёт «до → после»: его можно применить, оставить исходную сетку или отменить
импорт. Исправление сшивает совпадающие вершины
с точностью 0,000001 мм и удаляет повторные/вырожденные грани. Для CAD и деталей слайсера
также закрываются простые отверстия: проходы рассматривают контуры до 4, 12 и 32 рёбер
в пределах выбранного размера. Многоугольники должны быть плоскими и выпуклыми.
После достижения замкнутости проходы прекращаются. Отверстия скана сохраняются. Большие/сложные разрывы,
неправильные нормали и самопересечения автоматически не исправляются этим режимом.
Отчёт указывает оставшиеся дефекты; исходный файл не меняется. Ctrl+Z после исправления
возвращает импортированную исходную сетку. CAD из старого проекта проверяется перед
картой, если ещё не был проверен в текущем сеансе; сначала также задаётся вопрос.
«Карта без лечения» продолжает расчёт без подготовки ремонта; «Отмена» прекращает запуск.

При вращении крупных моделей (от 100 тысяч граней) каркас временно скрывается и
восстанавливается после отпускания мыши. Геометрия не упрощается. Неподвижная сцена
перерисовывается по изменениям, куб рисуется вместе со сценой без отдельного нативного окна. Замеры и
оставшиеся ограничения: [производительность](docs/PERFORMANCE.md).

1. Создайте проект «Предеформация». CAD загружается из STL, STEP или STP, скан — из STL.
   STEP переводится в миллиметры и триангулируется с выбранным отклонением (по умолчанию
   0,05 мм) и угловым отклонением в градусах (по умолчанию около 14,324°).
   Оба параметра доступны в одном диалоге. Тела сборки импортируются одной сеткой с сохранением взаимного расположения.
   Координаты STL интерпретируются как миллиметры; автоматического определения единиц STL нет.
2. Совместите модели автоматически или задайте минимум три пары неколлинеарных маркеров.
   Подгонка измеряет расстояния до треугольников CAD и использует выборку по площади.
   Режимы поиска используют 12/30/60 тысяч точек; обычный и длинный проверяют 24 ориентации
   главных осей и кандидата по локальным признакам. Допуск и минимальная доля площади скана
   в допуске настраиваются. Показаны RMSE совпавшей части и P95 всей выборки. При неоднозначной
   ориентации симметричной детали используйте маркеры. Расчёт можно отменить.
3. Постройте карту отклонений. У замкнутого CAD знак определяется внутри/снаружи тела.
   Если CAD имеет разрывы, карта использует расстояние до ближайшей поверхности и
   знак по нормали грани CAD; программа сообщает об этом в журнале. Возле разрывов
   и острых рёбер этот знак неоднозначен. Скан может быть открытым в обоих режимах.
   Выберите нужную карту в таблице перед установкой выносок.
4. Задайте плотность выборки, тип сети, предел поиска отклонений и минимальное покрытие.
   Дискретизация влияет на обучение: точки распределяются по площади поверхности.
   «Нет» использует исходные вершины CAD.
5. Рассчитайте деформацию или компенсацию. Коэффициенты XY/Z управляют компенсацией;
   стрелки показывают фактически применённое смещение, включая знак и коэффициент.
6. Выберите результат в таблице для экспорта в STL. Под таблицей показаны покрытие,
   контрольная RMSE и максимальное расстояние до подтверждённого измерения.

Одновременно выполняется одна фоновая операция. Отмена кооперативная: текущий вызов
геометрической библиотеки может завершиться не сразу. Принудительное уничтожение
потоков не используется. Закрытие окна ждёт остановки задачи.

## Настройки отображения и помощь

Во вкладке «Настройки и помощь» доступны параметры отображения, список горячих
клавиш, справка, сведения о программе и ручная проверка обновлений. «Параметры»
позволяют выбрать фон сцены, сглаживание контуров (MSAA ×4 по умолчанию, ×8, FXAA
или отключение) и скрытие рёбер крупных сеток на время вращения. Настройки сохраняются
между запусками и применяются к слайсеру и предеформации. Сглаживание не меняет сетку:
для более точного контура CAD нужно повысить качество триангуляции при импорте.
Цветные оси куба закреплены за одной вершиной и не переходят на другие рёбра при вращении.

## Сечения в слайсере

«Импорт детали» принимает STL, STEP и STP. Эти файлы также можно перетащить из проводника
в активную сцену; для STEP выберите CAD/BREP или сетку STL в окне импорта.
В режиме обзора двойной щелчок левой кнопкой по детали устанавливает центр вращения
на её центр, а по пустому месту возвращает его в центр плиты. Выбор в списке деталей
центр не меняет. В режимах выбора поверхностей и измерений используйте Alt + двойной щелчок.
В панели «Отображение → Сечения» включите
нужные плоскости XY, XZ, YZ. «+» удаляет сторону положительной нормали, «−» — отрицательной.
Позиция — координата вдоль нормали в мм. Её меняют числом, ползунком или кнопками ◀/▶
с указанным шагом. Несколько плоскостей действуют одновременно; до шести плоскостей
позволяют, например, оставить тонкий слой между двумя параллельными отсечениями.

Редактируемая плоскость выбирается щелчком по её ячейке, включая поле позиции.
Под таблицей показан номер выбранного сечения. Простое наведение мыши не переключает
ползунок; колёсико над полем без фокуса не меняет его значение.

«Указать» показывает перетаскиваемую плоскость выбранной строки. Тип «Произв.» разрешает
её вращение мышью; «Выровнять» направляет камеру перпендикулярно плоскости.
Цвет относится к манипулятору. «Экспорт» сохраняет контуры выбранного сечения видимых
деталей в VTP. «Сброс» отключает отсечения и возвращает три базовые плоскости.

Отсечения меняют только отображение: сетка, объём и STL-экспорт остаются целыми.
Срезанные поверхности не закрываются искусственными крышками. Настройки сечений
сохраняются в `.mrp`; платформа и её габариты не отсекаются.

### CAD / STEP (BREP)

При импорте STEP по умолчанию сохраняется исходная BREP-геометрия. В слайсере тела
можно загрузить отдельными деталями; в предеформации сборка остаётся одной номинальной
моделью. Кнопка CAD над сценой выбирает целую CAD-поверхность для поддержек.
Поддержки хранятся внутри детали и сохраняют привязку к CAD-граням при смене качества сетки.
Панель «CAD / STEP» доступна в инструментах слайсера и рядом с загрузкой CAD в предеформации:
повторная триангуляция, разделение тел, точные свойства, экспорт STEP и преобразование в сетку.
Перемещения, вращения, масштаб и отражение сохраняют BREP; после изменения треугольников
экспорт устаревшего CAD блокируется. Расчёты и поддержки используют сетку выбранной точности.
Подробнее: [CAD и ограничения](docs/CAD.md).

### Отображение

Рабочая лента содержит 25 команд: виды камеры, гладкое затенение, упрощённый вид,
сетка и линейки, зоны, габариты, центры масс, подписи и координаты, цвета, нависания,
геометрические проверки, оценки объёма/материала/заполнения камеры, PNG, буфер обмена и печать.
Три оценки включаются списком в группе «Статистика» и обновляются справа сверху
для выбранных деталей с их поддержками. Плотность и цену материала задайте через
стрелку «Оценка стоимости материала». Клик по детали выбирает её, клик в пустоте
сбрасывает выбор; рамка из пустого места выбирает несколько деталей. Shift добавляет,
Ctrl переключает выбор, Alt позволяет вращать сцену из пустого места.
Переключатели не меняют геометрию. Проверки габаритов не являются симуляцией печати.
[Описание команд](docs/DISPLAY.md).

## Инструменты слайсера

На вкладке «Инструменты» работают «Создать», «Дублировать», «Пакетное дублирование»,
«Перемещать», «Вращать», «Масштабировать» и «Отзеркалить». Создаются параллелепипед,
цилиндр или сфера с заданными размерами и центром. Для остальных команд отметьте
детали в столбце «Выбранные» текущей сцены.

Окна преобразований немодальные: можно работать с 3D-сценой рядом с ними.
«Применить» фиксирует отдельный шаг истории и оставляет окно открытым; «Да» применяет
и закрывает. «Закрыть» убирает неприменённый предпросмотр; уже применённые шаги остаются.
«Создать копию» сохраняет оригинал и применяет преобразование к новой детали.
Эти же команды доступны на вкладке «Расположение».

- Перемещение: абсолютные результирующие координаты и относительный сдвиг по XYZ;
  начало по минимуму, центру, максимуму или заданной координате каждой оси, общее
  либо индивидуальное. Начало можно указать на поверхности. Кнопки возврата используют
  положение при открытии инструмента. Линия задаётся двумя точками или координатами;
  перемещение проецируется на неё. В сцене доступны стрелки и привязка к шагу.
- Вращение: углы X → Y → Z, привязка 3D-дуг к угловому шагу, центр выбранного,
  индивидуальные центры либо заданная точка. Для вращения вокруг линии задайте её
  концы и угол. «Сохранять исходное положение по Z» сохраняет нижнюю точку каждой детали.
- Масштаб: фактор, конечный размер и разница синхронизированы; равномерный режим
  связывает оси. В индивидуальном режиме таблица описывает первую выбранную деталь,
  а факторы применяются ко всем. Подгон измерения использует расстояние между двумя
  выбранными точками и желаемую длину. Библиотека содержит inch → mm и mm → inch,
  поддерживает создание, редактирование и удаление наборов; она сохраняется в настройках
  приложения. Можно задать центр и сохранить нижнюю Z-координату.
- Отражение: YZ/XZ/XY либо произвольная плоскость через три неколлинеарные точки
  или точку и нормаль. Позиция плоскости задаётся координатами; «Центр детали»
  проводит плоскость через центр каждой выбранной детали. Плоскость видна в сцене.

Точки выбираются левой кнопкой на исходной поверхности; на время выбора предпросмотр
скрывается. Привязка задаёт шаг манипулятора, точный ввод чисел не округляется к шагу.
Пока окно инструмента открыто, другие изменения проекта и история заблокированы.
Закройте окно, чтобы отменить или повторить применённые преобразования.

Обычное дублирование задаёт число новых копий и вектор шага. Пакетное создаёт массив
Nx × Ny × Nz с шагами по осям; количество включает исходную ячейку. Исходные детали
сохраняются, новые копии выделяются. За один раз допускается до 1000 копий и до 512 МБ
массивов геометрии. Автоматическое размещение без пересечений не выполняется.

## История изменений

«Назад» (`Ctrl+Z`) отменяет изменение, «Вперёд» (`Ctrl+Y` или `Ctrl+Shift+Z`) повторяет его.
История охватывает модели, результаты расчётов, маркеры, настройки, видимость и сечения.
Каждое применение инструмента, включая массив копий, отменяется целиком. Быстрые изменения
полей и ползунков объединяются до паузы в 300 мс. После отмены новое изменение удаляет
ветку повтора. Возврат к сохранённому состоянию убирает звёздочку в заголовке.

История действует в текущем сеансе проекта и очищается при создании или открытии проекта;
в `.mrp` сохраняется текущее состояние. Хранится до 30 шагов, с сокращением старых снимков
при превышении 256 МБ геометрии; текущий и предыдущий снимки сохраняются даже для крупных
моделей. Неизменённые сетки разделяются между снимками. На время фоновых задач отмена
и повтор блокируются.

## Сохранение

`Ctrl+S` сохраняет текущий `.mrp`; «Сохранить проект как» выбирает новый путь.
Звёздочка в заголовке означает несохранённые изменения. Перед новым проектом,
открытием другого и закрытием программа предлагает сохранить изменения.

Формат `.mrp` 2.1 хранит все результаты, карты отклонений, векторные поля,
маркеры, выноски, настройки расчёта и отображения, детали и платформы. Вершины,
грани и массивы записываются без преобразования в STL, чтобы сохранить индексы
и точность. Запись атомарная; повреждённый входной файл не очищает текущую работу.
Проекты 1.x и 2.0 читаются, новые сохраняются как 2.1. Старые версии приложения не
поддерживают новый формат.

## Текущее состояние

В рабочей области слайсера щелчок по детали выбирает её; Shift/Ctrl позволяют менять
множественный выбор. «Выгрузить деталь» и «Сохранить выбранные детали как» работают
с отмеченными деталями текущей сцены. Выгрузка поддерживает Ctrl+Z/Ctrl+Y. Щелчок
правой кнопкой открывает круговое меню с выгрузкой, перемещением, вращением и экспортом;
перетаскивание правой кнопкой сохраняет навигацию камеры.

Панель над сценой выбирает треугольник, связную плоскость, плавную поверхность,
связную оболочку, кистью или рамкой. Сначала отметьте нужные детали. Выделенные грани
подсвечиваются оранжевым и учитывают сечения. Для плавной поверхности и кисти доступен
угол между соседними гранями; радиус кисти задаётся в мм. Рамка выбирает видимые
треугольники. Shift добавляет, Ctrl вычитает, Alt позволяет двигать камеру, Esc
снимает выделение и возвращает выбор деталей. Выделение граней временное и в `.mrp`
не записывается; оно сбрасывается при изменении геометрии и восстановлении истории.

Во вкладке «Поддержки» доступны генерация для видимых деталей, генерация для выбранных,
ветвящиеся поддержки, ручное размещение и предпросмотр областей. Настраиваются угол
нависания от горизонтали, шаг, диаметры стойки/контакта/основания, высоты сужения и
основания, Z платформы. Можно ограничиться выделенными поверхностями. Стойки идут
вниз по Z до ближайшей поверхности; режим «Только до платформы» пропускает контакты
над препятствиями. Ручной режим принимает щелчки по направленным вниз поверхностям;
для доступа снизу поверните вид или включите сечения. Esc завершает ручной режим.
Поддержки хранятся группами внутри исходной детали, отображаются зелёным и экспортируются
вместе с ней в STL. Формат `.mrp` 2.1 сохраняет их геометрию, области поверхности,
типы и параметры. Поддержки перемещаются, вращаются, масштабируются, отражаются и
копируются вместе с деталью. Повторная кнопка предпросмотра убирает красную подсветку.

«Поддержки вручную» переключает левую панель на список областей и параметры поддержек.
Выберите деталь в верхнем списке, выделите поверхность инструментами над сценой,
нажмите «Добавить область», выберите тип и «Перестроить 2D и 3D». Доступны блок
(стенки по сетке), линии (стенки вдоль X), точечные стойки, сеть диагональных связей,
контур, усечённые конусы и ветвление. «Отсутствует» убирает геометрию, сохраняя область.
Щелчок по строке группы выбирает её поверхность; группа имеет собственные параметры,
видимость и действие удаления. Можно сохранять профили параметров. «Указать точку
вручную» размещает отдельные контакты на выбранной детали; «К деталям» возвращает
обычную панель. Ранее созданные отдельные детали поддержек в старых проектах остаются
отдельными: их исходная привязка не была записана.

Куб в слайсере и предеформации имеет светлые грани и тонкие рёбра без прямоугольной подложки:
щелчок по грани направляет камеру по её нормали,
двойной щелчок включает изометрию. Масштаб вида сохраняется. Платформа автоматически
становится прозрачной на 88% при положении камеры ниже Z=0 и возвращает непрозрачность
при взгляде сверху.

В «Измерениях» доступны расстояние между точками с ΔX/ΔY/ΔZ, перпендикуляр до
продолжения плоскости грани, ближайшая точка поверхности детали, расстояние между
параллельными плоскостями, окружность по трём точкам (R, диаметр, центр), угол по трём
точкам и угол между плоскостями. Выберите режим, нажмите «Выбрать» и укажите точки
в сцене. Вторая точка задаёт вершину измеряемого угла. Результаты видны в панели и 3D;
их можно скрыть, очистить или скопировать. Esc заканчивает выбор. Измерения временные:
они не сохраняются в проекте и сбрасываются при изменении геометрии, чтобы не показывать
устаревшие значения. Измерения выполняются по триангуляции, не по аналитическим STEP-граням.

Ветвление реализовано собственным алгоритмом, не является Materialise e-Stage.
Стойка — замкнутая сетка; ветви состоят из пересекающихся замкнутых тел без булева
объединения. Параметры не учитывают процесс печати, материал или прочность. Проверка
препятствий использует геометрические лучи, а не полную проверку объёма контактов.

Перетаскивание заголовка и краёв окна передано системе: Windows предлагает Snap,
если эта возможность включена в её настройках. Двойной щелчок по заголовку переключает
обычный и развёрнутый вид. Кнопка «Отменить расчёт» в строке состояния доступна
во время фоновой операции.

Работают импорт STL/STEP, экспорт STL, сечения, совмещение, карты отклонений, нейросетевая компенсация,
управление сценой, платформами и проектами, история изменений. Отдельные модули отчётов и
инспектирования, неподключённые команды ленты и экспорт CLS из интерфейса отключены.
Экспериментальный CLS-код требует проверки совместимости с конкретной машиной.
Запретные зоны сейчас визуализируются; проверка столкновения детали с ними не реализована.

Нейросеть аппроксимирует измеренные смещения, а не моделирует физику печати.
Синтетические тесты не подтверждают производственные допуски или время обработки
многомиллионных сеток. Подробности — в [описании проверок](docs/VALIDATION.md).

## Разработка и сборка

Актуальные команды PyInstaller и Inno Setup: [сборка Windows](docs/BUILD_WINDOWS.md).

```powershell
python -m unittest discover -s tests -v
python scripts/smoke_desktop.py --sections --tools
python -m pip install -r requirements-dev.txt
python -m PyInstaller Meshropractor.spec
```

Расчёты находятся в `ml_deformation.py`, `geometry_analysis.py` и `Workers_Meshropractor.py`;
архивы — в `project_store.py`; жизненный цикл проектов и задач — в `project_controller.py`
и `background_tasks.py`; интерфейс и сцена — в `UI_Meshropractor.py` и `Meshropractor.py`.
