# Дублирование деталей

Выберите детали в активной сцене и откройте **Инструменты → Дублировать**
или **Пакетное дублирование**. Оба окна задают матрицу по X/Y/Z; пакетный
вариант по умолчанию включает ещё один ряд по Y.

**Количество** по каждой оси включает исходную ячейку. Например, 3 × 2 × 1
даёт шесть комплектов: исходный и пять новых. При двух выбранных деталях
итого получится 12 деталей, из них 10 новых.

**Промежуток** — свободное расстояние между габаритами соседних комплектов,
в миллиметрах. Шаг равен размеру выбранного комплекта по оси плюс промежуток.
Поддержки учитываются в габаритах. Выбранные детали перемещаются одним
комплектом, сохраняя расположение между собой.

**Предпросмотр в сцене** показывает полупрозрачные виртуальные копии.
Изменение количества или промежутка обновляет их расположение. Сцену можно
вращать и приближать. Виртуальные копии нельзя выбрать; они не попадают в
список деталей, сохранённый проект, объёмы или экспорт. Показ можно отключить.
Геометрия предпросмотра общая между экземплярами, без копирования сеток при
каждом изменении промежутка.

**Создать копии** добавляет реальные детали и их поддержки на исходную
платформу; CAD/BREP и маркировки сохраняются и перемещаются вместе с деталью.
Новые детали выделяются. **Закрыть**, Esc и закрытие приложения удаляют
неприменённый предпросмотр. Операция отменяется и повторяется целиком.

**Запомнить значения** сохраняет матрицу и промежутки при подтверждении.
Ограничения: 1000 новых деталей и 512 МБ массивов геометрии за одну операцию.
Недопустимая матрица блокирует подтверждение. Проверка пересечений внутри
исходного комплекта не выполняется; промежутки разделяют его общие габариты.
