# Создание детали

Откройте **Инструменты → Создать**. Форма выбирается в списке сверху;
справа показана схема с обозначениями размеров. Окно, схема и подписи
поддерживают светлую и тёмную темы.
Схемы рисуются только контуром, без заливки граней и подложек под буквами.
Размерные линии показывают направления X/Y/Z и радиусы R/R1/R2; у круглых
форм плавные эллипсы основания и отдельная линия высоты H.

| Форма | Параметры |
| --- | --- |
| Параллелепипед | X — ширина, Y — глубина, Z — высота. |
| Цилиндр | R — радиус, D — диаметр, H — высота. |
| Труба | R1/D1 — наружный радиус/диаметр, R2/D2 — внутренний, H — высота. |
| Конус | R1/D1 — нижнее основание, R2/D2 — верхнее, H — высота. R2=0 создаёт вершину, R2>0 — усечённый конус. |
| Пирамида | X/Y — прямоугольное основание, H — высота. |
| Призма | R/D — описанная окружность основания, N — число сторон (3–128), H — высота. |
| Сфера | R — радиус, D — диаметр. |
| Тор | R1 — расстояние до центра круглого сечения, R2 — радиус самого сечения. Наружный диаметр: 2(R1+R2). |
| Скруглённый параллелепипед | X/Y/Z — наружные габариты, R — радиус скругления рёбер и углов. |
| Параллелепипед с фасками | X/Y/Z — наружные габариты, C — размер фаски. |

Радиус и диаметр связаны: изменение одного поля обновляет другое. Схема
меняется вместе с размерами. «Центр в координатах сцены» задаёт центр габаритов;
это не обязательно центр масс, например у конуса или пирамиды.
**Поставить низ на Z=0** изменяет Z центра так, чтобы нижняя точка была на плите,
сохраняя X/Y. Созданная деталь относится к активной платформе; в общей сцене
она остаётся без привязки к платформе. Создание поддерживает Undo/Redo.
У тора штриховая окружность показывает линию центров сечения, а маленькая
штриховая окружность — само круглое сечение. Указатели R/C в упрощённых схемах
параллелепипедов показывают скруглённый угол или фаску.

## Допуск и треугольники

**По допуску** — детализация криволинейных поверхностей рассчитывается в мм.
На окружности контролируется расстояние от дуги до хорды; для сферы, тора и
скруглений допуск распределяется между двумя направлениями кривизны.
Меньше допуск — больше треугольников. По умолчанию: 0,01 мм.

**По числу сегментов** — число участков окружности задаётся вручную, 12–2048.
Этот режим не гарантирует выбранный допуск. Для тора число применяется к
обоим окружностям; для сферы меридианы имеют примерно половину числа участков.
У призмы число сторон задаётся параметром N, независимо от детализации.
Плоские грани параллелепипеда, пирамиды и фасок не требуют допуска кривизны.

Оценка треугольников показывается до создания. Максимум — 250 000 треугольников;
слишком малый допуск или слишком большое число сегментов отклоняется с пояснением.
Программа не ухудшает детализацию автоматически. Недопустимые радиусы трубы,
тора, скругления или фаски также блокируют создание. Результат — замкнутая
треугольная сетка с параметрами создания в метаданных проекта; это не BREP-тело.
