# Расположение деталей

Вкладка «Расположение» содержит две группы со всеми 13 командами из базового и
автоматического разделов образца. Группы «Расширенные» и «По умолчанию» не добавлены.
На узком окне доступна горизонтальная прокрутка ленты, в том числе колесом мыши.

Сначала отметьте детали в таблице. Преобразования и размещение относятся к отмеченным
деталям текущей сцены; дочерние поддержки перемещаются вместе с ними. Операции сохраняют
параметры отображения, имена, связи поддержек с гранями и исходные файлы.

| Команда | Как работает |
| --- | --- |
| Перемещать | Точные координаты или смещение XYZ, привязка, начало отсчёта, перенос вдоль линии; стрелки в сцене. |
| Вращать | Углы XYZ, центр или ось вращения, привязка по углу; дуги в сцене. |
| Свободное перемещение | Перетаскивание детали левой кнопкой: всё выделение движется вместе в плоскости экрана либо XY/XZ/YZ. Доступны шаг привязки и точные смещения. |
| Масштабировать | Коэффициенты по осям или конечные размеры, равномерный масштаб, центр и создание копии. |
| Отзеркалить | Отражение относительно осевой либо заданной плоскости, с возможностью создать копию. |
| Верхняя/нижняя поверхность | По щелчку на треугольнике поворачивает деталь так, чтобы его нормаль смотрела вверх или вниз. Можно поставить нижнюю точку детали с поддержками на Z = 0. |
| Автоматическое размещение | Раскладывает детали на платформе с зазором и отступом от краёв; по желанию поворачивает на 90° вокруг Z. |
| Оптимизация положения | Ищет ориентацию по высоте, площади габаритов XY, площади нависаний или габаритному объёму. |
| Сравнение положений | Для одной детали готовит таблицу вариантов с метриками. Выбор строки переключает предпросмотр; применяется выбранный вариант. |
| Минимизировать ограничивающий параллелепипед | Подбирает поворот, уменьшающий объём осевого габаритного параллелепипеда; размеры и форма детали не меняются. |
| Подогнать под платформу | Перемещает выбранную группу в рабочие габариты, при разрешении подбирает её общую ориентацию. Взаимное положение и масштаб деталей сохраняются. |
| Сортировать по форме | Выбранная деталь служит образцом ориентации для похожих моделей. Центр каждой модели сохраняется; непохожие детали пропускаются с пояснением. |
| 3D-размещение | Размещает детали по всему объёму камеры, включая несколько уровней по Z. По желанию доступны повороты на 90° по всем осям. |

## Предпросмотр и применение

Новые автоматические команды запускаются кнопкой «Подготовить результат». Расчёт идёт
в фоне, показывает текущий этап и допускает отмену. Предпросмотр меняет только матрицы
отображения: исходная геометрия остаётся в проекте до «Применить». Закрытие окна или
ошибка расчёта восстанавливает первоначальный вид. Изменение параметров сбрасывает
устаревший результат. Применение — один шаг Undo/Redo, включая перенос на другую платформу.

В свободном перемещении предварительный вид обновляется во время перетаскивания.
Alt + мышь оставляет доступным вращение сцены. Esc отменяет текущий жест перетаскивания;
закрытие окна отменяет весь неприменённый перенос. В выбранной координатной плоскости
курсор должен смотреть на неё не с ребра — иначе нужно повернуть сцену.

В командах раскладки выберите платформу, зазор между деталями, отступ от краёв XY
и нижний уровень по Z. Для подгонки группа считается единым объектом, зазор внутри
неё не изменяется. При предпросмотре показывается целевая платформа; после применения
открывается её вкладка. Учитываются все невыбранные детали целевой платформы, включая
скрытые, и их поддержки. Назначение деталей платформе сохраняется в проекте.

## Критерии и ограничения

- Алгоритмы раскладки используют ограничивающие параллелепипеды с зазором. Полости
  не используются для вложения одной детали в другую; круглые запретные зоны учитываются
  по охватывающему квадрату с настоящим диапазоном высоты. Это консервативная упаковка,
  а не точный геометрический nesting. Отказ означает, что поиск не нашёл подходящий
  вариант в своих пределах, а не доказанную невозможность размещения.
- За одну операцию размещаются до 200 деталей. Поиск ограничен объёмом геометрии,
  числом свободных областей и кандидатов; превышение лимита не меняет проект.
- Оптимизация сравнивает ограниченный набор осевых ориентаций, вариантов габаритного
  параллелепипеда и укладки на крупные грани. Площадь XY — площадь габаритного прямоугольника.
  Нависания оцениваются по нормалям и площади треугольников; это не прогноз объёма
  поддержек, времени печати или прочности. Глобальный оптимум не гарантируется.
- Подгонка и автоматическая раскладка не масштабируют модели. Если группа слишком
  велика, уменьшите её состав или явно измените масштаб отдельной командой.
- «Сортировать по форме» поддерживает до 30 выбранных деталей с образцом. Совпадение
  проверяется по расстояниям до треугольников в обе стороны на выборках поверхности
  и вершин, с заданным допуском в мм. Это приближённая проверка сходства. Симметричные
  модели могут иметь несколько равноценных ориентаций; итог нужно проверить.
- При смене ориентации существующие поддержки поворачиваются вместе с деталью.
  Проверьте их опору и при необходимости перестройте. 3D-размещение не генерирует
  новые опоры и не проверяет возможность печати «висящих» деталей конкретным оборудованием.
- Нативный шаг геометрического поиска может завершиться до обработки запроса отмены.

По смыслу переноса ориентации и сравнения критериев ориентировались на официальные
описания [Shape sorter](https://www.materialise.com/en/inspiration/articles/optimized-nesting-how-to)
и [Orientation tools](https://www.materialise.com/en/academy/industrial/magics/video-tutorials/orientation-tools).
Реализация использует собственные открытые алгоритмы; полной эквивалентности Magics нет.
