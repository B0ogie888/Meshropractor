# Текстуры и цвета

[О проекте](../README_RU.md) · [Руководство](USER_GUIDE_RU.md)

Вкладка **«Текстуры»** содержит 15 активных команд в группах «Главная»,
«Отображение» и «Цвет». Команды работают с деталями текущей сцены слайсера.
Можно работать как с STL, так и с сеткой отображения STEP/BREP. Окраска и
изображения не меняют CAD-геометрию, выбор CAD-граней или дочерние поддержки.

## Наложение

1. Выберите деталь щелчком в сцене или отметьте несколько деталей в таблице.
2. Для наложения только на часть поверхности выделите её нижней панелью:
   треугольник, CAD-грань, плоскость, связная область, кисть или рамка.
3. Нажмите **«Новая текстура»** и выберите PNG, JPEG, BMP, TIFF или WebP.
4. В диалоге задайте название, проекцию, повторения U/V, смещение и угол.
   Изображение показано в предпросмотре. «Применить» накладывает текстуру,
   «Отмена» сохраняет прежний внешний вид.

Без выделенных поверхностей текстура накладывается на все треугольники
отмеченных деталей. Для каждой детали создаётся независимая копия.
Проекция **«По граням»** выбирает плоскость XY/XZ/YZ по нормали треугольника;
также доступны явные плоскости, цилиндрическая и сферическая проекции.
Параметры строятся по габаритам выбранной области. При перемещении, вращении,
масштабировании и отражении привязка остаётся на тех же углах треугольников.

## Команды

| Команда | Действие |
| --- | --- |
| Новая текстура | Добавить изображение на выделенные поверхности или выбранные детали. |
| Деталь-в-текстуру | Запечь текущие цвета треугольников в растровый атлас. Цвет существующих изображений берётся в центре треугольника; мелкие детали изображения при запекании не сохраняются. |
| Выбрать текстуру | Открыть список текстур всех загруженных деталей, включая другие платформы. Выбор переключает сцену владельца, выделяет деталь и треугольники текстуры. |
| Редактировать текстуру | Изменить название, изображение и параметры проекции выбранного слоя. Для исходной UV и атласа цветов можно сохранить прежнюю развёртку либо выбрать новую проекцию. |
| Обновить текстуру | Перечитать файл изображения. Для атласа цветов пересчитать цвета детали. Если источник не задан, выбрать файл; при ошибке чтения прежняя текстура сохраняется. |
| Копировать текстуру | Сохранить изображение и параметры выбранного слоя во внутреннем буфере приложения. |
| Вставить текстуру | Добавить копию на выбранные детали/поверхности. Проекция пересчитывается для новой области; исходная UV/атлас при переносе на другую деталь используют проекцию по граням. |
| Удалить текстуру с треугольников | Снять выбранный слой только с выделенных треугольников его владельца. |
| Удалить текстуру | Удалить выбранный слой целиком. |
| Переключить отображение текстур | Скрыть или показать сохранённые текстуры и цвета всей сцены. |
| Обратить отображение текстур | Переключить видимость выбранного слоя. |
| Покрасить деталь | Задать цвет всех треугольников выбранных деталей, сняв изображения с этих треугольников. |
| Разделить деталь по цветам | Создать отдельные сетки по точным RGBA-цветам; для изображений используется цвет в центре треугольника. |
| Покрасить поверхности | Задать цвет выделенных треугольников, в том числе выбранной целиком CAD-поверхности. |
| Цвет треугольников | Включить/выключить сохранённые цвета и текстуры; состояние синхронизировано с общим отображением текстур. |

Новые слои перекрывают предыдущие в своей области. Если снять или скрыть
верхний слой, виден нижний. В списке указаны название владельца, название
текстуры, количество треугольников и видимость. После смены выбранной детали
команда использует её единственный слой либо предлагает список.

Диагностическая разноцветная сетка во вкладке **«Отображение»** остаётся отдельным
режимом: она показывает номера треугольников цветами палитры, а не сохранённую
окраску. Её включение выключает показ текстур.

## Сохранение и ограничения

Изображения, развёртки, области, цвета, названия слоёв и видимость хранятся
в `.mrp`. После сохранения исходный файл изображения не нужен для просмотра.
Изменения отменяются **Ctrl+Z** и повторяются **Ctrl+Y**. Удаление слоя не
удаляет деталь. При ремонте, меняющем состав или нумерацию треугольников,
устаревшая привязка текстуры отключается; наложите текстуру на новую сетку снова.

Разделение по цветам создаёт **сетки**, включая исходный CAD: BREP у полученных
цветовых фрагментов отсутствует. Разрезанные цветовые области могут быть открытыми;
это не автоматическое разделение на замкнутые печатные тела. Геометрия поддержек
сохраняется, номера поверхностей пересчитываются. Если одна группа поддержек
охватывает разные цвета, операция прекращается с объяснением: сначала разделите
либо удалите эту группу. Поддержка без привязанных граней переходит в группу
цвета ближайшего центра треугольника.

На детали допускается до 32 слоёв; при разделении — до 256 точных цветов.
Изображение принимается до 16 мегапикселей и уменьшается до 2048 пикселей по
большей стороне. Кэшированный атлас отображения ограничен примерно 16 мегапикселями;
при большом числе повторений или слоёв разрешение отображения уменьшается.
Прозрачность изображения сводится к белому фону. Текстуры меняют внешний
вид, **не создают рельеф для печати**. Обычный STL не хранит эти растровые слои,
а экспорт STEP сохраняет CAD-геометрию без изображений; для полного внешнего вида
используйте `.mrp`. Интеграция с проприетарным форматом текстур Magics и его
Build Processor не реализована.
