# Редактирование и структуры в «Инструментах»

Лента сохраняет создание, копирование и преобразования. Дополнительно
доступны 22 команды по образцу панели Magics. Группы прокручиваются горизонтально,
в том числе колесом мыши. SVG-иконки находятся в `assets/ribbon/tools/`.

Выберите детали текущей сцены и откройте команду. Настройте параметры, нажмите
«Подготовить», проверьте зелёный предпросмотр и сообщение о результате, затем
«Применить». Расчёт фоновый и допускает отмену; до применения исходная геометрия
не меняется. Закрытие отменяет предпросмотр. Применение — один шаг Undo/Redo.
У «Маркировки» свой редактор: область задаётся рамкой на детали, затем можно
сохранить редактируемую заготовку либо срастить рельеф с исходником.
Команда «Создать» открывает [параметрическое создание детали](PRIMITIVES.md)
со схемой размеров и допуском построения сетки.

Изменяющие геометрию команды создают **сетки**, включая операции с STEP/BREP.
BREP и привязки слоёв текстур к прежним треугольникам удаляются из результата: экспорт изменённой модели как
исходного STEP запрещён; Undo восстанавливает CAD. Если у детали есть поддержки,
сначала удалите их и после изменения поверхности создайте заново. Добавление
распорок, лотка, формообразующей оболочки или массива поверхности сохраняет исходную деталь и её поддержки.
«Фрагменты в детали» использует существующее разделение с переносом поддержек
по привязанным поверхностям.

## Редактировать

| Команда | Как работает |
| --- | --- |
| Пустотелая деталь | Внутренняя полость при заданной толщине стенки. Нужен замкнутый исходник. Отводные отверстия добавляйте отдельно. |
| Разрезание | Точка и нормаль задают плоскость. Создаются две отдельные детали с закрытыми срезами. |
| Перфорации | Регулярная сетка сквозных цилиндрических отверстий вдоль выбранной оси; центры расположены с половины шага от минимальных габаритов. Максимум 400 отверстий, шаг больше диаметра. |
| Корпус и ядро | Отдельные наружный корпус с заданной стенкой и внутреннее ядро. Если ядро исчезает при заданной толщине, применение не предлагается. |
| Поверхность в массив | Предварительно выделите грани нижней панелью выбора. Создаются 1–100 копий участка с шагом вдоль средней нормали; исходник сохраняется. Копии — открытые поверхности, не готовые замкнутые детали. |
| Скругление | Сферическое открытие объёма с заданным радиусом: выпуклые участки сглаживаются внутрь, тонкие выступы могут исчезнуть. Это приближённая операция по полю, без выбора отдельных CAD-рёбер. |
| Выдвинуть | Предварительно выделите участок поверхности. Призма вдоль средней нормали объединяется с исходником; отрицательная величина вычитает призму. Лучше выбирать плоский связный участок. |
| Смещение | Перемещение всех вершин по их нормалям на заданную величину. Самопересечения автоматически не исключаются: проверьте результат мастером исправлений. |
| Заокругленное смещение | Смещение объёмного поля, затем сферическое открытие с выбранным радиусом. Может менять форму и удалять тонкие элементы. |

## Объединение

«Объединить детали» собирает сетки в одну запись, **сохраняя** внутренние
пересечения. «Булевы операции» предлагает объединение, вычитание и пересечение
замкнутых ориентированных тел через Manifold. «Фрагменты в детали» разделяет
связные оболочки. Для объединения и булевых действий детали должны относиться
к одной платформе. Первая выбранная деталь **в порядке списка** — основная,
остальные — инструменты; после применения они заменяются результатом.

## Сгенерировать

«Маркировка» открывает редактор областей на поверхности выбранной детали:
текст, рисунки, проекция и Data Matrix. Область задаётся рамкой ЛКМ прямо в
сцене; рельеф можно сохранить запланированным, объединить с деталью или
выгрузить отдельным STL. См. [маркировку поверхности](MARKING.md).

«Распорки» создаёт отдельный замкнутый цилиндр между двумя координатами с
заданным радиусом. Это геометрия, без расчёта нагрузки и прочности.

## Структуры

| Команда | Заполнение внутри исходного тела |
| --- | --- |
| Сотовые структуры | Вертикальные шестигранные стенки. Размер ячейки задаёт расстояние между горизонтальными параллельными сторонами шестигранника. |
| Структуры | Кубическая решётка цилиндрических рёбер вдоль X/Y/Z. |
| Структуры на основе срезов | Горизонтальные слои рёбер с чередованием X и Y. |
| Тетраэдрическая решётка | Четыре периодических семейства диагональных рёбер. |
| Диагональная решётка по срезам | Диагональные рёбра по горизонтальным слоям с чередованием направления. |

Размер ячейки, толщина рёбер/стенок, шаг расчёта и толщина наружного корпуса
настраиваются. Нулевая наружная стенка оставляет только структуру, ограниченную
исходным телом. Здесь нет фирменных рецептур DSM Somos/TetraShell или прогноза
поведения материала. Геометрия может иметь несколько отдельных компонентов;
при необходимости используйте «Фрагменты в детали».

Пустотелость, корпус/ядро, скругления, решётки и формообразующая оболочка
рассчитываются по полю расстояний. Шаг определяет детализацию и время обработки.
Толщина должна быть не меньше двух шагов расчёта; максимум 3 млн узлов поля и
2 млн треугольников выбранных моделей и суммарного результата, до 200 выходных частей.
При превышении бюджета увеличьте шаг. Изменение
шага не происходит автоматически. Перед изготовлением проверьте размеры,
связность, толщину и отверстия результата.

## Оснастка

- «Фиксатор (лоток)» добавляет открытый прямоугольный лоток по габаритам одной
  детали с заданным зазором и толщиной стенок/дна. Исходник сохраняется.
- «Формообразующая оболочка» добавляет оболочку вокруг выбранной детали
  с зазором и толщиной, сохраняя исходник. Замкнутая оболочка может требовать
  дополнительного разреза для извлечения.
- «Удаление объёмов» вычитает остальные выбранные замкнутые тела из первого.

Это собственные геометрические инструменты. Они не реализуют фирменные модули
RapidFit/FormFit или машинный формат Concept Laser, не подбирают сборочную
оснастку автоматически и не проверяют прочность или возможность извлечения.
