# Иконки ленты

Здесь находятся SVG-иконки команд. Приложение читает их при запуске. Для изменения
достаточно отредактировать нужный файл в Inkscape, другом SVG-редакторе или текстовом
редакторе и перезапустить программу из исходников. Для уже собранного приложения
нужно заменить соответствующий файл в `_internal/assets/ribbon/` либо собрать новую версию.

| Каталог | Где используется |
| --- | --- |
| `main/` | Главная; имена файлов совпадают с названиями команд. |
| `tools/` | Инструменты: `0` — создать, `1` — дублировать, `2` — пакетное дублирование, `3` — переместить, `4` — вращать, `5` — масштабировать, `6` — отразить; `cad` — CAD/BREP. Новые операции: `hollow`, `cut`, `perforate`, `shell_core`, `lattice` и другие. |
| `repair/` | Исправление сеток. |
| `texture/` | Текстуры и цвета; например, `new.svg` — новая текстура. |
| `placement/` | Расположение. |
| `analysis/` | Анализ и отчёты; например, `walls.svg` — анализ толщины. |
| `display/` | Отображение. |
| `settings/` | Настройки и помощь. |
| `workspace/` | Платформы, поддержки и нижняя панель выбора поверхностей. |

Иконки над подписями имеют одинаковый логический размер **28 × 28**. SVG масштабируется
для DPI экрана; координаты рисунка обычно задаются через `viewBox="0 0 48 48"`.
Сохраняйте `viewBox` и прозрачный фон, располагайте рисунок внутри его границ. Если
рисунок занимает маленькую часть холста, он будет выглядеть меньше остальных даже
при одинаковом размере кнопки. Малые иконки рядом с текстом и иконки вкладок
масштабируются отдельно.

Названия файлов менять не нужно: соответствие командам указано в `src/*_ribbon.py`,
`src/workspace_icons.py` и `src/settings_icons.py`. `src/ribbon_layout.py` задаёт
общий размер и высоту кнопок с учётом строк подписи. Если файла нет, используется
резервный рисунок из кода. `scripts/assets/export_ribbon_icons.py` извлекает исходные
рисунки и не перезаписывает существующие SVG, сохраняя ручные правки.

Тема перекрашивает пиктограммы по их альфа-каналу: в светлой теме они графитовые,
в тёмной — светлые. Поэтому детали внутри рисунка должны разделяться прозрачными
промежутками. Не добавляйте непрозрачный цветной фон под шахматную текстуру:
после перекрашивания он сольётся с узором. В `texture/` используются контуры,
открытая сетка и отдельные штрихи вместо сплошной подложки.
